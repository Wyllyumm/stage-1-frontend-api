# stage-1-frontend-api

Front end code for NewExplorer App (final project)

- About:
  This project utlizes newsapi, a public api, in order to send request and bring back data. In this case users are able to search for any topic of their choosing, whether that be sports, food, tech, cars, etc. This app will allow users to also save, or bookmark these news articles so they can come back and read up on these articles in their free time. Once signed in, users will be able to navigate to their profile page in order to see all the articles they have personally saved.

- Languages/technologies:
  In order to render these articles, this app uses React, db.json, ReactRouter
